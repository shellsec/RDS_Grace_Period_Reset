# Windows Server RDS宽限期重置工具

## 概述
本工具包用于解决Windows Server远程桌面服务(RDS)宽限期问题。当系统提示"远程桌面授权模式尚未配置，远程桌面服务将在120天内停止工作"时，可以使用此工具重置宽限期。

## 兼容性说明

### 完全支持的版本
- **Windows Server 2012 R2** ✅ (主要测试版本)
- **Windows Server 2012** ✅ 
- **Windows Server 2008 R2** ✅
- **Windows Server 2008** ✅

### 部分支持的版本
- **Windows Server 2016** ⚠️ (可能需要额外配置)
- **Windows Server 2019** ⚠️ (可能需要额外配置)
- **Windows Server 2022** ⚠️ (可能需要额外配置)

### 版本差异说明
- **2008/2008 R2/2012/2012 R2**: 注册表路径和服务名称完全相同，脚本可直接使用
- **2016及以上版本**: 
  - 注册表结构基本相同，但可能有额外的安全限制
  - 某些版本可能使用不同的授权验证机制
  - 建议先在测试环境验证

### 注册表路径对比
所有支持版本的注册表路径都相同：
```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM\GracePeriod
```

## 文件说明

### 核心脚本

#### 1. RDS_Grace_Period_Reset.bat
- **功能**: 手动重置RDS宽限期的主脚本（标准版）
- **作用**: 删除GracePeriod注册表项，重启RDS服务，可选择重启服务器
- **特点**: 
  - 支持自动模式（计划任务调用时自动重启）
  - 自动备份注册表
  - 验证重置结果
- **使用**: 右键以管理员身份运行
- **计划任务模式**: 传递 `auto` 参数时自动重启服务器

#### 2. RDS_Grace_Period_Reset_NoReboot.bat
- **功能**: 无需重启服务器的重置脚本（无重启版）
- **作用**: 仅重启RDS服务，影响最小化
- **特点**:
  - 仅重启RDS服务（1-2分钟中断）
  - 自动记录详细日志
  - 支持自动模式（计划任务调用）
- **使用**: 右键以管理员身份运行
- **适用场景**: 生产环境，需要最小化影响

### 计划任务管理脚本

#### 3. Create_Scheduled_Task.bat
- **功能**: 创建自动化计划任务（标准版-需重启）
- **作用**: 设置每3个月自动执行重置脚本并重启服务器
- **特点**:
  - 自动传递 `auto` 参数实现自动重启
  - 使用系统最高权限运行
  - 执行时间：凌晨2:00
- **使用**: 右键以管理员身份运行

#### 4. Create_Scheduled_Task_NoReboot.bat
- **功能**: 创建无重启版本的计划任务
- **作用**: 设置自动化执行，可选择执行频率
- **特点**:
  - 支持自定义执行频率（每月/每2个月/每3个月/自定义）
  - 支持自定义执行时间
  - 自动重试机制（失败时10分钟后重试）
  - 生成监控脚本
- **使用**: 右键以管理员身份运行

#### 5. Delete_Scheduled_Tasks.bat
- **功能**: 删除所有RDS相关计划任务
- **作用**: 清理已创建的自动化任务和相关文件
- **特点**:
  - 显示任务详细信息
  - 可选择删除日志和备份文件
- **使用**: 右键以管理员身份运行

### 验证和检查脚本

#### 6. Check_GracePeriod.bat
- **功能**: 检查RDS宽限期状态的完整工具
- **作用**: 通过多种方法验证宽限期是否已重置
- **检查方法**:
  1. 检查注册表GracePeriod项
  2. 检查TermService服务状态
  3. 通过PowerShell WMI查询宽限期天数
- **使用**: 右键以管理员身份运行

#### 7. Check_GracePeriod_Simple.bat
- **功能**: 简化版宽限期检查工具
- **作用**: 快速检查宽限期状态（避免复杂的PowerShell命令）
- **特点**: 简单可靠，适合快速验证
- **使用**: 右键以管理员身份运行

#### 8. Check_GracePeriod.ps1
- **功能**: PowerShell版本的检查脚本
- **作用**: 提供更详细的宽限期信息
- **特点**: 
  - 彩色输出
  - 详细的系统信息
  - 跨版本兼容性更好
- **使用**: 右键以管理员身份运行（PowerShell）

## 快速开始

### 🚀 推荐方案：无重启版本
**适用于生产环境，影响最小**

**立即解决问题（无重启）:**
1. 右键点击 `RDS_Grace_Period_Reset_NoReboot.bat`
2. 选择"以管理员身份运行"
3. 脚本会自动处理，仅重启RDS服务（1-2分钟中断）
4. 无需重启服务器，宽限期重置为120天
5. 运行 `Check_GracePeriod_Simple.bat` 验证结果

**设置自动化（无重启）:**
1. 右键点击 `Create_Scheduled_Task_NoReboot.bat`
2. 选择"以管理员身份运行"
3. 选择执行频率（推荐每2个月）
4. 选择执行时间（推荐凌晨2:00）
5. 系统将创建全自动计划任务
6. 任务执行时会自动调用脚本，无需人工干预

### 🔄 标准方案：需重启版本
**适用于测试环境或彻底重置**

**立即解决问题（需重启）:**
1. 右键点击 `RDS_Grace_Period_Reset.bat`
2. 选择"以管理员身份运行"
3. 按提示操作，建议选择重启服务器
4. 重启后宽限期将重置为120天
5. 运行 `Check_GracePeriod_Simple.bat` 验证结果

**设置自动化（需重启）:**
1. 右键点击 `Create_Scheduled_Task.bat`
2. 选择"以管理员身份运行"  
3. 系统将创建每3个月自动执行的计划任务
4. 任务执行时会自动重启服务器（无需人工确认）
5. 可选择立即测试运行一次

### 🔍 验证宽限期状态
**检查重置是否成功:**
1. 运行 `Check_GracePeriod.bat` 或 `Check_GracePeriod_Simple.bat`
2. 重新登录RDS会话，查看是否还显示宽限期警告
3. 如果显示，应该显示"120天"
4. 如果未生效，请重启服务器

### 🗑️ 删除自动化任务
**清理所有计划任务:**
1. 右键点击 `Delete_Scheduled_Tasks.bat`
2. 选择"以管理员身份运行"
3. 选择删除选项（可删除单个或全部任务）
4. 可选择清理相关日志和备份文件

## 注册表操作详解

### 目标注册表路径
```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM\GracePeriod
```

### 操作原理
- Windows在启动时检查此注册表项来确定宽限期剩余天数
- 删除此项后，系统会重新创建并重置为120天
- 需要重启服务器或RDS服务使更改完全生效
- 注册表项包含加密的宽限期信息

### 备份机制
- 脚本执行前会自动备份整个RCM注册表项
- 备份文件命名格式：`RCM_Backup_YYYYMMDD_HHMM.reg`
- 备份文件保存在脚本所在目录

## 监控和维护

### 检查宽限期剩余天数

**方法1：使用检查脚本（推荐）**
```cmd
# 运行完整检查脚本
Check_GracePeriod.bat

# 或运行简化版
Check_GracePeriod_Simple.bat
```

**方法2：PowerShell命令**
```powershell
# 在服务器上运行PowerShell命令
(Get-WmiObject -Class Win32_TerminalServiceSetting -Namespace root\cimv2\TerminalServices).GracePeriodDays
```

**方法3：直接查看RDS会话**
- 重新连接RDS会话
- 如果重置成功，应该显示"120天"或不再显示警告

### 查看计划任务状态
1. 打开"任务计划程序" (taskschd.msc)
2. 找到以下任务之一：
   - `RDS_Grace_Period_Reset`（标准版）
   - `RDS_Grace_Period_Reset_NoReboot`（无重启版）
3. 查看上次运行时间和结果
4. 可手动运行或修改计划

### 日志文件位置
- **注册表备份文件**: `RCM_Backup_YYYYMMDD_HHMM.reg`
- **无重启版日志**: `RDS_Reset_Log_YYYYMMDD_HHMM.txt`
- **Windows事件日志**: 事件查看器 → Windows日志 → 系统

### 监控脚本
运行 `Create_Scheduled_Task_NoReboot.bat` 后会自动生成：
- **Monitor_RDS_Task.bat**: 快速查看任务状态和日志

## 故障排除

### 常见问题

**1. 脚本执行失败**
- 确保以管理员权限运行
- 检查UAC设置
- 临时关闭杀毒软件
- 检查脚本文件编码（应为UTF-8）

**2. 注册表项删除失败**
- 使用regedit手动删除
- 检查注册表权限设置
- 确保没有其他程序占用
- 尝试重启后再次执行

**3. 服务重启失败**
- 检查是否有活动的远程桌面连接
- 手动停止并启动TermService服务
- 检查服务依赖关系
- 查看Windows事件日志

**4. 计划任务创建失败**
- 确保任务计划程序服务正在运行
- 检查系统策略限制
- 手动通过任务计划程序创建
- 验证脚本路径是否正确

**5. 编码显示问题**
- 脚本已使用UTF-8编码（chcp 65001）
- 如果仍显示乱码，检查控制台字体设置
- 建议使用Windows PowerShell或命令提示符

**6. 宽限期验证失败**
- WMI查询可能在某些版本不支持（正常现象）
- 使用检查脚本验证注册表项
- 重新登录RDS会话查看实际提示
- 如果未生效，尝试重启服务器

### 手动操作方法

**手动删除注册表项:**
1. 运行 `regedit`
2. 导航到 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM`
3. 删除 `GracePeriod` 子项
4. 重启服务器或RDS服务

**手动重启RDS服务:**
```cmd
net stop TermService /y
net start TermService
```

**手动验证宽限期:**
1. 重新连接RDS会话
2. 查看是否还显示宽限期警告
3. 如果显示，应该显示"120天"
